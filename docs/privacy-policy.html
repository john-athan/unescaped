Unescaped privacy policy

Effective 7 October 2026

What it reads

When you press the button or use the menu entry, Unescaped reads the tab you clicked on: your selection, the type of the document and, if it is plain text, its text. In Google Drive it reads the id of the open or selected file and downloads that one file with your own Drive session.

What it keeps

The HTML is held in the browser's session storage only until the tab that shows it closes. Nothing is synced, persisted or logged.

What it sends

Nothing. There is no server, no analytics and no account. The only request the extension itself makes is the Drive download, to Google, for the file you asked for. The page you render may load its own images and stylesheets, as it would in any browser.
